An optional block theme for a site that exists to hold a PressShot Library.

== Description ==

PressShot is a block theme for a dedicated PressShot Library site. It makes the Library the home page in a full-window layout, gives share pages an image-first frame, and brings the PressShot brand to the login screen. It needs the PressShot plugin, which works with any theme; this theme only dresses it up.

Light and dark modes come from the Light Dark Toggle block by the WordPress.com Special Projects team, if it's installed. Without it, the site stays light.
