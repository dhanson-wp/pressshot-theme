# PressShot theme

PressShot is an optional block theme for a dedicated PressShot Library site. It gives the Library and its share pages the PressShot look: paper, ink, and cobalt, with Fraunces for the site name and headings.

It needs the PressShot plugin, which provides the Library block. Any block theme works with the plugin, so use this one only if you want the site to match the app.

Light and dark modes work through the Light Dark Toggle block, if you have it installed.
