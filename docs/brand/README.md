# PressShot WordPress theme brand

The theme mark puts the official WordPress symbol inside the PressShot capture card.

Use icon.svg for square placements, lockup-light.svg on light surfaces, and lockup-dark.svg on dark surfaces. social.png is a 1280 × 640 repository social preview. Keep proportions unchanged and clear space of at least one quarter of the icon width. Use the WordPress theme label where the component matters. The Mac app identity is unchanged.
